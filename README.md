# FamilyQuest

Сімейний застосунок, який перетворює домашні обов'язки на квести з XP і винагородами.
Батьки створюють завдання, дитина виконує, батьки підтверджують — і тільки після
підтвердження нараховуються XP та коіни.

Тут — як запустити й де що лежить. Що це за продукт, для кого і чому ухвалено саме такі
рішення — у [PROJECT.md](PROJECT.md). Формальна продуктова специфікація з дорожньою
картою — у [BRD.md](BRD.md).

## Запуск

```bash
npm install
```

Локальна база піднімається однією командою — інсталювати PostgreSQL і мати права
адміністратора не потрібно:

```bash
npx prisma dev -n familyquest -d
```

Вона надрукує рядок підключення. Впиши його в `.env` (шаблон — у `.env.example`),
далі створи схему й запускай:

```bash
npm run db:migrate
```

```bash
npm run dev
```

Застосунок буде на http://localhost:3000

Перший крок — створити сім'ю на `/register`, потім додати дитину на `/parent/family`.
Дитина заходить на `/login` у вкладці «Я дитина» за логіном і паролем, які задали батьки.

## Стек

Статуси та причини нарахувань зберігаються рядками, а не enum-ами: так їх набір
розширюється без міграції схеми — у Хвилі 2 саме так додався статус «Втрачене».

## Правила гри

**Статуси завдання**

```
Активне ──[дитина: «Виконано»]──> Очікує перевірки
   │                                    │
   │                     ┌──────────────┴──────────────┐
   │              [підтвердити]                 [відхилити + коментар]
   │                     │                              │
   │                Виконане                       Відхилене
   │             (+XP, +коіни)                          │
   │                                      [дитина виконує повторно]
   │<──────────────────────────────────────────────────┘
   │
   └──[минув термін]──> Прострочене
```

XP і коіни нараховуються **лише** в момент підтвердження батьками — ніде більше.
Підтвердження остаточне.

**Рівні.** Щоб перейти з рівня N на N+1, треба `100 + (N-1) × 50` XP.
Тобто 100, 150, 200, 250… XP ніколи не витрачається.

**Коіни.** Внутрішня валюта. `coinsBalance` — доступно зараз, `coinsEarnedTotal` —
зароблено за весь час (ніколи не зменшується). Виплата зменшує лише баланс.

Кожне нарахування й списання записується окремим рядком у `LedgerEntry` — це основа
для майбутньої історії, досягнень і серій виконань.

## Що вже є (Хвиля 1)

- Спільний батьківський акаунт (email + пароль) і окремі акаунти дітей (логін + пароль)
- Батьки бачать логін дитини і можуть задати новий пароль; поточний ніде не зберігається
  у відкритому вигляді
- Разові завдання: назва, опис, дитина, дедлайн з часом, XP, коіни; редагування й видалення
- Повний цикл: «Виконано» з коментарем дитини → перевірка → підтвердження або відхилення
  з коментарем → повторне виконання
- Шість статусів завдання, автоматичний перехід у «прострочене»
- XP, прогресивні рівні, коіни, виплати з історією
- Панелі батьків і дитини, PWA, українська мова, mobile-first
- Світла й темна теми з режимом «як у системі»; вибір зберігається на пристрої

## Що додала Хвиля 2

- **Повторювані завдання.** Шаблон із вибором днів тижня й часу дедлайну; екземпляр
  народжується сам при першому відкритті застосунку в потрібний день. Пропущені дні не
  добираються: після тижня без застосунку дитина не отримає сім прострочених «почистити зуби».
- **Зарахування без перевірки.** Прапорець на шаблоні: дитина натискає «Виконано» — XP
  нараховуються одразу. Для дрібних щоденних звичок, які не варті трьох десятків
  підтверджень на місяць.
- **Таймер зникнення.** Після дедлайну квест ще деякий час видно зі зворотним відліком,
  далі він стає «Втраченим» і зникає в дитини, лишаючись в історії у батьків. Тривалість
  налаштовується (за замовчуванням 60 хвилин).
- **Сімейний екран.** Діти бачать рівні, XP і серії одне одного — без коінів.
  Вимикається одним перемикачем у налаштуваннях.
- **Серія виконань.** Скільки днів поспіль є хоча б одне зараховане завдання.
  Рахується з журналу нарахувань, не зберігається окремо.

## Що додала Хвиля 3

- **Магазин нагород.** Батьки виставляють нагороди з ціною в коінах, дитина обмінює
  зароблене. Коіни списуються одразу при заявці — інакше той самий баланс можна було б
  «витратити» на кілька нагород, поки батьки не бачать. При відмові повертаються повністю.
- Черга видачі в батьків — поруч із чергою перевірки завдань.
- Історія обмінів зберігає назву й ціну на момент обміну: зміна ціни не переписує минуле.

## Що додала Хвиля 4

- **Компаньйон.** Один на дитину, з трьома шкалами: ситість, настрій, енергія.
  Шкали спадають із часом, але піднімаються лише зірочками, які дає підтверджене
  завдання — улюбленець живе з виконаних обов'язків, а не з частоти відкривання застосунку.
- **Компаньйон не хворіє й не помирає.** Шкали не падають нижче порогу; найгірший
  стан — «дрімає». Тиждень відсутності не зустрічає дитину провиною.
- **Кімната.** Фіксовані слоти з предметами, які відкриваються рівнем. Так XP нарешті
  щось відмикає, лишаючись невитратним.
- **Графіка через реєстр.** Спрайти описані в `lib/companion/sprites.ts`; тимчасові
  генерує `npm run sprites`. Замінити малюнок = покласти PNG із тим самим іменем
  у `public/sprites` — реєстр і компоненти при цьому не змінюються.

## Розгортання

Продакшен: **https://familyquest.site** — VPS Ubuntu, Node 22, PostgreSQL 18, Nginx.

| Що | Де |
| --- | --- |
| Код | `/var/www/familyquest` |
| Рядок підключення й змінні | `/etc/familyquest/env` (поза каталогом проєкту, `640 root:familyquest`) |
| Служба | `familyquest.service`, слухає `127.0.0.1:3000` |
| Nginx | `/etc/nginx/sites-available/familyquest` — зворотний проксі |
| Сертифікат | Let's Encrypt, автопоновлення через `certbot.timer` |

Застосунок працює під окремим системним користувачем `familyquest` без права входу.
Назовні відкриті тільки 80, 443 і 22 — база й сам застосунок доступні лише з localhost.

### Оновити продакшен

```bash
familyquest-deploy
```

Скрипт сам робить копію бази перед оновленням, тягне код, ставить залежності,
застосовує міграції, збирає й перезапускає службу. Зупиняється на першій помилці:
якщо збірка впаде, службу він не чіпає — сайт продовжує працювати на старій версії.

### Резервні копії бази

Щодня о 04:00 (таймер `familyquest-backup.timer`), зберігаються 30 днів
у `/var/backups/familyquest`. Зняти копію просто зараз:

```bash
familyquest-backup
```

Відновлення з копії:

```bash
gzip -dc /var/backups/familyquest/familyquest-ДАТА.sql.gz | sudo -u postgres psql familyquest
```

Копії лежать **тільки на сервері** — від втрати самого сервера вони не рятують.
Зовнішнє сховище поки не налаштоване.
